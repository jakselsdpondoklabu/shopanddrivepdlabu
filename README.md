# shopanddrivepdlabu.com

Website Resmi & Sistem Katalog Produk Shop & Drive Pondok Labu, Jakarta Selatan.

## Fitur Utama
- **Landing Page Interaktif**: Layanan bengkel, promo, estimasi harga, dan testimoni.
- **Katalog Produk & Suku Cadang**: Aki mobil, oli mesin, shockbreaker, spooring ban, dan suku cadang Astra Otoparts.
- **Preview 5 Banner Beranda**: Pengaturan fleksibel produk unggulan di halaman utama.
- **Dashboard Admin (CMS)**: Manajemen konten dan katalog mandiri (`/#admin`).
- **Direct WhatsApp Conversion**: Tombol konsultasi dan pemesanan otomatis ke admin cabang.
- **Integrasi Cloud Database**: Supabase PostgreSQL & Cloud Storage untuk upload foto produk mandiri.

## Struktur Direktori
- `app/` : Aplikasi frontend React 19 + Tailwind CSS + Vite.
- `supabase/` : Skema database SQL (`schema.sql`) untuk tabel produk dan storage bucket.
- `Assets/` : Aset gambar & dokumentasi pendukung.

## Panduan Menjalankan Lokal
```bash
cd app
npm install
npm run dev
```
Buka `http://localhost:5173` di peramban.
